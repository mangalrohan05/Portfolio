## 📦 Deployment & Running Locally

The portfolio is lightweight and runs entirely client-side, requiring zero external build dependencies or static page compilations.

To run it locally:
1. Clone the repository:
   ```bash
   git clone https://github.com/mangalrohan05/Portfolio.git
   ```
2. Double-click `index.html` to open it in your browser, or serve it via any basic static web server (such as Live Server in VS Code).
